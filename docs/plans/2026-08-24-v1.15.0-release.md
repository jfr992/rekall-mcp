# Rekall v1.15.0 Release Plan

## Problem narrative

The branch adds a public, retry-safe AFK memory operation contract and closes two production gaps discovered while qualifying it: memory publication can no longer race between YAML and vector storage, and authenticated Rekall deployments now work end-to-end with Docker Compose and Codex. These are distributable server and client changes, not local-only configuration, so leaving them on an unpublished branch would strand every existing `uvx` and container user on v1.14.0. Because the release adds new API behavior, SemVer requires a minor release (`1.15.0`), not a patch.

The repository contract still applies: prepare and review a PR first; do not tag, publish, or merge from this branch. The `v1.15.0` tag is created from `main` only after the PR merges.

## Architecture

```text
AFK client
  └─ POST /api/memory/afk/save
       └─ normalized + sanitized operation envelope
            ├─ scoped writer lock ──► authoritative YAML record
            └─ reconciliation ──────► Qdrant vector publication

Authenticated operator
  ├─ Docker Compose forwards REKALL_API_TOKEN ──► Rekall middleware
  └─ Codex stores env-var name only
       ├─ MCP Authorization: Bearer <runtime secret>
       └─ hooks Authorization: Bearer <runtime secret>

release PR ──merge by human──► main ──tag v1.15.0──► GHCR + PyPI
```

## TDD blocks

1. **RED — release contract**
   - Require `pyproject.toml` and the editable `uv.lock` package to report `1.15.0`.
   - Require the latest migration section to be `v1.14.0 → v1.15.0` and document AFK operations, bearer auth, and no data migration.
   - Preserve the v1.14.0 migration section as historical documentation.

2. **GREEN — release metadata and notes**
   - Bump the package metadata through `uv version 1.15.0`.
   - Prepend concise upgrade, rollback, and authenticated-client instructions to `docs/MIGRATION.md`.

3. **VERIFY — branch before PR**
   - Run the full default suite (paid `eval_live` and wheel lanes remain opt-in).
   - Run the embedded lane and the wheel gate when CI executes the PR.
   - Confirm `git diff --check`, release metadata parity, and no secret bytes in tracked files.
